# 🎵 Soasound

**Soasound** est un site web de vente d'instruments de musique, conçu pour présenter différents instruments et accessoires musicaux à travers une interface moderne, simple et intuitive.

Le projet a été réalisé entièrement avec des technologies web front-end.

## 📌 Présentation

Soasound est une boutique en ligne dédiée aux passionnés de musique.

Le site permet aux visiteurs de découvrir différents instruments de musique, de consulter les produits et de naviguer facilement à travers les différentes sections de la boutique.

L'objectif est de proposer une expérience utilisateur agréable et une présentation claire des produits.

## 🎯 Objectifs du projet

* Créer un site web moderne pour la vente d'instruments de musique
* Présenter les produits de manière attractive
* Faciliter la navigation des utilisateurs
* Concevoir une interface simple et intuitive
* Adapter le site aux différents formats d'écran

## 🎼 Produits

Le site peut présenter différentes catégories d'instruments et équipements musicaux :

* 🎸 Guitares
* 🎹 Claviers
* 🥁 Batteries et percussions
* 🎻 Instruments à cordes
* 🎤 Microphones
* 🎧 Accessoires audio
* 🎵 Autres équipements musicaux

## 🚀 Installation et utilisation

Aucune installation particulière n'est nécessaire.

### 1. Télécharger ou cloner le projet

```bash
git clone https://github.com/bovielline-glitch/Soasound.git
```

### 2. Ouvrir le dossier

Accéder au dossier du projet :

```bash
cd Soasound
```

### 3. Lancer le site

Il suffit d'ouvrir le fichier :

```text
index.html
```

avec un navigateur web.

Vous pouvez simplement **double-cliquer sur `index.html`** pour lancer le site.

Les navigateurs tels que **Google Chrome, Microsoft Edge ou Mozilla Firefox** peuvent être utilisés.
